01 · Foundation

What is an AI agent?

The simplest useful definition is: an AI agent is a system given a goal that can decide which actions to take in order to achieve that goal.

A normal AI interaction often looks like:

You → question → AI → answer

An agentic system can be more like:

Goal → decide → use a tool → observe the result → decide again → complete the goal

The important difference is that the system can participate in a process rather than simply producing one response.

Agent component · Model

The LLM provides the intelligence layer.

A large language model processes language and generates responses. In an agent system it can interpret instructions, evaluate information, reason about possible actions and determine which available capability may be useful next.

The model itself is not automatically an agent. The surrounding application supplies the instructions, context, tools and execution environment that turn model capability into an agentic system.

Explore AI →
Agent component · Instructions

Instructions define the job.

An agent needs a clear objective and boundaries. Instructions can define what the agent should accomplish, what information it should use, what tools it may access and what it must not do.

A vague instruction such as "find affiliate opportunities" is less useful than a defined objective such as "identify legitimate affiliate programmes using authoritative sources and flag anything requiring human verification."

Agent component · Context

Context is what the model can see now.

Context can include the user's request, previous messages, relevant documents, retrieved information, tool results and the current state of the task.

Good agent systems do not necessarily provide everything they know at once. They retrieve or supply the information that is relevant to the current decision.

Understand memory →
Agent component · Memory

Memory is stored information.

Memory can allow an application to retain information across tasks or interactions. It might be stored in a database, application memory system, knowledge base or another data store.

Memory and context are related but not identical. Memory is stored information that can be retrieved; context is information currently provided to the model.

A knowledge base can also be searched to retrieve relevant information for the model. This is one of the ideas behind retrieval-augmented generation, commonly called RAG.

The key idea

The agent loop.

The defining pattern is not simply "AI + tools". It is the ability to use the result of an action to determine what should happen next.

01

Goal

The system receives a defined outcome it is expected to pursue.

02

Decide

The model determines what action or information is needed next.

03

Act

The system calls an available tool or performs an allowed action.

04

Observe

The result of the action becomes new information for the system.

05

Decide again

The system can determine whether another action is required.

06

Complete

The process stops when the defined outcome has been achieved or the system requires human intervention.

Agent behaviour

Planning and task decomposition.

A larger goal may require several smaller actions. An agentic system can break a goal into tasks, perform them and adjust its approach when the results change what is required.

For example, researching a company could involve checking its official website, searching relevant partner networks, comparing evidence and preparing a recommendation.

Control matters

Agents need boundaries.

Permissions

What can it access?

An agent should receive only the access required for its job. Read access and write access should be treated differently.

Validation

What evidence does it need?

Important decisions should be based on appropriate evidence rather than assumptions or unverified claims.

Limits

When should it stop?

Systems can use execution, cost, action and time limits to prevent uncontrolled loops or unnecessary activity.

Human approval

When should a person decide?

Important, irreversible, financial or public actions can require human approval before execution.
