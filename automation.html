Automation

Connect the work.

Automation is the layer between your tools. Capture an input once, move it through a workflow with logic, and deliver an output without repeating the same manual work.

The core model

Trigger → Logic → Action.

Most useful automations can be understood through these three layers. Something starts the workflow, the system determines what should happen, and one or more actions produce the result.

01 · Trigger

What starts an automation?

A trigger is the event that starts a workflow. Instead of someone repeatedly checking for something to happen, the system waits for a defined event.

The right trigger depends on where the information or event originates.

Trigger

Form submission

Start a workflow when someone submits information.

Trigger · Form

Form submission

A form is one of the simplest ways to start an automation. Someone provides information and that submission becomes the input for the workflow.

For example, an enquiry form could capture a name, email address and request before sending the information into an AI classification step.

Trigger · Email

New email

Incoming email can become the starting point for a workflow. The system can identify the message, extract useful information and decide what should happen next.

This is useful when messages follow predictable patterns, such as enquiries, notifications or routine requests.

Trigger · Schedule

Scheduled workflows

Some work does not depend on another person doing something first. A scheduled trigger can start a workflow at a defined time or interval.

Examples include recurring reports, content preparation, reminders and routine data processing.

Trigger · Webhook

Webhooks

A webhook allows one system to send an event or payload into another workflow. This creates a direct connection between applications.

Webhooks are particularly useful when an application needs to tell an automation platform that something has happened.

Logic · Conditions

Conditions

Conditions allow an automation to make a simple decision based on information already available in the workflow.

For example: if an enquiry is marked as urgent, route it one way. If it is not urgent, use another path.

Explore routing →
Logic · AI

AI classification

AI can analyse information that is difficult to handle with simple rules. It can classify messages, extract useful information or identify the likely intent behind an enquiry.

This creates a bridge between traditional automation and more flexible AI-powered workflows.

Logic · Routing

Routing

Routing sends different types of information to the appropriate destination.

A sales enquiry could go to one workflow, a support request to another and a general question to a different response path.

Data transformation
